email, defeats, wallart, cave, impacting, pi, peoplesvote, blames, mcclure, 👣, croati, desk, zazzle, numerous, mediter, eleng

這十六個 token 描述的是一張海蝕洞的照片。它們是寫給機器的，沒有任何人挑選過它們。遺傳演算法在 CLIP（許多圖像生成器中連結圖片與文字的模型）的字典裡搜尋，找出 CLIP 自己認為與這張照片最相近的序列：每一代 2048 個候選，共兩百代，每次都留下更接近的那些。

結果讀起來像雜訊：croati、mediter 這類只剩一半的字，一個商店名稱，一個政治標籤，一串腳印。然而從未參與這場搜尋的圖像模型，卻能從中畫出一個洞穴。這些 token 以數字的形式直接交給每個模型，跳過把文字切成 token 的那一步，所以這首詩只存在於機器自己的詞彙裡。

這件作品把這樣的序列當作寫給機器的詩來讀。我們不是收信人，只是在一旁偷聽。

比文字更接近

CLIP 判斷這張照片與五種描述有多接近：
（偷懶的）人類，“a photo of a cave and the ocean”：0.272
這十六個 token：0.433
ChatGPT：0.258
JoyCaption Beta One：0.271
Gemini：0.273

這十六個 token 分數最高，是因為搜尋推高的正是這個分數。真正重要的是，從未看過這場搜尋的其他圖像模型，依然把它們讀成一個洞穴。
