This tool talks to small language models on your own computer, nothing goes to the cloud. Before you start:
  1. Install Ollama: ollama.com/download
  2. In a terminal, pull the two models: ollama pull gemma3:4b and ollama pull embeddinggemma
  3. Allow the browser to talk to Ollama:
    Mac in a terminal: launchctl setenv OLLAMA_ORIGINS "*", then quit and reopen Ollama
    Windows
    1. Search environment variables in the Start menu
    2. Click Edit environment variables for your account
    3. Click New → Variable name: OLLAMA_ORIGINS · Value: *
    4. Click OK
    5. Reopen Ollama from the Start menu
    1. Im Startmenü nach Umgebungsvariablen suchen
    2. Umgebungsvariablen für dieses Konto bearbeiten anklicken
    3. Neu klicken → Variablenname: OLLAMA_ORIGINS · Wert: *
    4. OK klicken
    5. Ollama über das Startmenü neu starten
  4. Download this tool (button above) and open the file in your browser.

Conditions for Emotions

recommended — gemma3:4b (generation, image, camera) · embeddinggemma (distance, axis, map, tokens)

image & camera need a vision model (gemma3:4b / llava); text-only models like gemma3:1b answer everywhere except those two.

restart applies a changed system prompt

a 262,144-entry SentencePiece dictionary, shared with Gemini · Ollama exposes no tokenizer — counts read from prompt_eval_count, boundaries measured by growing the prefix one character at a time (merges approximate)

PCA 768→2 · drag to pan · scroll to zoom

cosine similarity in 768-dimensional space

semantic differential (Osgood 1957) · position = cos(w,B) − cos(w,A)

click a token to take that path

same sentence, one substitution, raw continuation — any language works

narration, not measurement

camera on file:// works in Firefox (allow when asked) — Chrome needs http://localhost
