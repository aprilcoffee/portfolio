Sixteen Tokens for a Cave

Year
2025
Status
In development
Type
Artistic Research, Multimodal Poetry
Materials
Genetic algorithm, CLIP ViT-L/14, image models
Topics
token poetry, genetic algorithm, CLIP, text-to-image, machine reading, multimodal poetry
With
Leon-Etienne Kühr
Link
Preliminary work in the 39C3 talk, 28:37–32:20 (media.ccc.de)

email, defeats, wallart, cave, impacting, pi, peoplesvote, blames, mcclure, 👣, croati, desk, zazzle, numerous, mediter, eleng

These sixteen tokens describe a photograph of a sea cave. They were written for a machine, and no person chose them. A genetic algorithm searched the dictionary of CLIP, the model that links pictures and words in many image generators, for the sequence that CLIP itself would match most closely with the photograph: 2048 candidates per generation, two hundred generations, each time keeping the ones that came closer.

The result reads like noise: half-words such as croati and mediter, a shop name, a political hashtag, footprints. Yet image models that took no part in the search draw a cave from it. The tokens are handed to each model as numbers, skipping the step in which written text would be cut into tokens, so the poem exists only in the machine's own vocabulary.

The work reads such sequences as poetry for machines. We are not the ones addressed; we only overhear.

Closer than words

How close CLIP finds the photograph and five descriptions of it:
(lazy) human, “a photo of a cave and the ocean”: 0.272
the sixteen tokens: 0.433
ChatGPT: 0.258
JoyCaption Beta One: 0.271
Gemini: 0.273

The tokens score highest because this score is exactly what the search pushed up. What counts is that other image models, which never saw the search, still read them as a cave.

Status
